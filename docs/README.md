## 推荐阅读顺序

1. 第一次接触项目：01 → 02 → 03 → 14。
2. 开始某个里程碑前：读 14 中该里程碑的任务，再读任务引用的章节。
3. 修改某个子系统前：读对应章节全文，以及 02 中的模块边界与内存预算。

## 术语

| 术语 | 英文 / 代码名 | 含义 |
| --- | --- | --- |
| 配置 | Profile | 一个 `.conf` 文件，描述代理、策略组、规则等全部行为 |
| 模块 | Module | 一个 `.amodule` 文件，可叠加到任意配置上的片段 |
| 策略 | Policy | 一个流量去向：内置动作（DIRECT、REJECT…）、代理节点或策略组 |
| 代理节点 | Proxy | 具体的出站服务器，如一个 Shadowsocks 服务器 |
| 策略组 | Policy Group | 由若干策略组成、按算法选出其中一个的策略 |
| 规则 | Rule | "条件 → 策略"的一条映射，按顺序匹配 |
| 规则集 | Rule Set / Domain Set | 从外部加载的一批规则或域名 |
| 外部资源 | External Resource | 规则集、节点订阅、远程脚本、GeoIP 数据库等通过 URL 获取的内容 |
| 运行包 | Active Bundle | App 提交给隧道的配置、模块和本地脚本的一致快照 |
| 运行配置 | RuntimeConfiguration | 隧道把运行包编译后得到的不可变内存结构 |
| 引擎 | Engine | 隧道扩展内的网络核心（`AetherEngine`） |
| 隧道 | Tunnel | Packet Tunnel 扩展（`AetherTunnel` target） |
| 出站模式 | Outbound Mode | 规则 / 全局代理 / 直连 |
| 功能开关 | Feature Switch | MitM、重写、脚本、抓包四个运行时开关 |
| 流 | Flow | 一个被引擎处理的 TCP 连接或 UDP 会话 |

## 文档中的标记

- **必须 / 不得**：硬性要求，违反即视为缺陷。
- **应 / 不应**：默认要求，偏离时需在提交说明中写明理由。
- **可**：可选实现。
- 🔬 **待真机验证**：设计基于公开文档或经验，必须在真机上确认后才能视为成立；验证结果回填到 [13-testing.md](13-testing.md) 的验收矩阵。
