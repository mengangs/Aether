# 12 界面规格

## 1. 原则

- 原生 SwiftUI，遵循 iOS 人机界面指南；SF Symbols；浅色 / 深色模式；动态字体到辅助功能尺寸；iPad 使用分栏布局。
- 信息优先于装饰：首页一眼能看到"连没连上、走哪条路、流量多少"。
- 每个错误都给出人能看懂的原因和下一步操作；错误码以小字附在说明后，便于反馈。
- 颜色不是唯一信号：延迟同时显示数字，状态同时显示文字。
- 视觉识别：主题色取一种偏冷的蓝紫（"以太"），用作强调色与图标；图标构思为一束穿过介质的光线，抽象、无文字。

## 2. 信息架构

`TabView` 五个标签：

| 标签 | SF Symbol（参考） | 内容 |
| --- | --- | --- |
| 首页 | `circle.hexagongrid` | 连接、出站模式、流量、常用策略组、功能开关、提醒 |
| 策略 | `point.3.connected.trianglepath.dotted` | 策略组与节点、测速 |
| 请求 | `list.bullet.rectangle` | 最近 / 活跃请求、详情 |
| 配置 | `doc.text` | 配置与模块管理、编辑器 |
| 工具 | `wrench.and.screwdriver` | 证书、DNS、规则测试、外部资源、统计、日志、脚本、诊断、设置 |

每个标签有自己的 `NavigationStack`；iPad 上"请求"和"配置"使用 `NavigationSplitView`。

## 3. 首次启动引导

1. **欢迎**：名称与标语 "Every packet, its own path."。
2. **获取配置**：从 URL 导入 / 从文件导入 / 使用示例配置 / 稍后。
3. **安装 VPN 配置**：先用一页说明即将出现的系统授权弹窗，点击按钮后才调用 `saveToPreferences`。
4. **完成**：进入首页。

任何一步都可跳过，跳过后首页显示对应的待办卡片。

## 4. 首页

自上而下：

1. **连接卡片**：大开关；状态文字（未安装 / 已断开 / 连接中 / 已连接 xx:xx:xx / 重新连接中）；当前配置名（点击弹出配置选择）。未安装 VPN 配置时替换为"安装 VPN 配置"按钮。
2. **出站模式**：分段控件"规则 / 全局 / 直连"；选"全局"时下方出现全局策略选择。
3. **流量卡片**：当前上 / 下行速率、最近 2 分钟曲线、本次连接累计；点击进入流量统计。
4. **策略组卡片**：配置中前 3 个非隐藏的 `select` 组（与状态快照的 `primaryGroups` 一致），显示当前节点与延迟；点击进入该组。
5. **功能开关**：MitM、重写、脚本、抓包。配置中没有相关内容时开关置灰并说明；MitM 在 CA 未信任时显示警告图标。
6. **提醒**：来自状态快照 `alerts` 与 App 自身检测——CA 未信任、GeoIP 数据库未配置、外部资源更新失败、脚本已停用、发生过内存压力、托管配置过期。每条可点击进入处理页面，可单条忽略（同一问题再次出现时重新显示）。

隧道运行时首页以 1 Hz 刷新（[10 §3](10-control-ipc.md#3-状态快照)）。连接开关有轻触觉反馈。

## 5. 策略

- 按配置顺序列出策略组（默认不显示隐藏组，工具栏可切换）。
- 组标题：名称、类型标签（手动 / 自动测速 / 故障转移 / 负载均衡）、当前选择、"测速"按钮。
- 成员行：名称、协议图标、延迟徽标（< 200 ms、< 500 ms、≥ 500 ms、失败四档颜色 + 数字或"超时"等文字）、当前选择的勾选标记。
- `select` 组点击成员即选择；自动类组点击成员进入节点详情，当前成员显示"自动"标签。
- 工具栏："全部测速"、搜索。
- **节点详情**：类型、服务器与端口、参数（敏感值以 `******` 显示，可按住查看）、能力（UDP）、最近 10 次测速、"测速"按钮、"复制为配置行"（脱敏）、所属策略组列表（可直接设为该组的选择）。`skip-cert-verify = true` 的节点显示安全警告。

## 6. 请求

### 6.1 列表

- 分段："最近 / 活跃"；搜索（主机、URL）；筛选：策略、协议、仅失败、仅 MitM。
- 行：主机（或 IP）、协议或方法徽标、最终节点、命中规则简写、↑↓ 字节数、耗时、状态图标。
- 可见时以 1 Hz 增量拉取（`getRequests` 的 `sinceID`）；用户滚动离开顶部时暂停自动插入，顶部显示"有 N 条新请求"。

### 6.2 详情

| 分区 | 内容 |
| --- | --- |
| 概览 | URL 或目标、方法、状态码、主机来源（请求 / Fake IP / 反查 / 嗅探）、实际连接地址、耗时分解条（DNS、连接、握手、首字节） |
| 路由 | 命中规则原文与来源（可跳转到编辑器对应行）、策略链 |
| 数据 | 上下行字节 |
| 备注 | 重写、脚本、拒绝原因等 |
| HTTP（可见时） | 请求头、响应头、Body（已抓包时）：JSON 格式化、图片预览、文本、十六进制 |

操作：复制 URL、复制为 cURL、导出 HAR、"添加规则…"、终止（活跃请求）。

**添加规则**：预填 `DOMAIN-SUFFIX` / `DOMAIN` / `IP-CIDR` 三种候选与策略选择器，写入一个自动创建并启用的本地模块"快速规则"（不直接改动配置文件，托管配置同样适用），提交并重载。

## 7. 配置

顶部分段："配置 / 模块"。

### 7.1 配置列表

- 行：名称、来源标签（本地 / 托管）、更新时间、当前配置勾选。点击切换配置（隧道运行时确认后重载）。
- 左滑：重命名、复制、分享（默认脱敏）、删除（当前配置不可删除）。
- 添加：从 URL、从文件、从剪贴板、扫描二维码（VisionKit `DataScannerViewController`）、新建空白、示例配置。
- 导入确认页：来源、内容预览、诊断摘要、将下载的外部资源列表；确认后写入。

### 7.2 编辑器

两种模式，可随时切换，编辑同一个 `ProfileDocument`：

- **文本模式**（Runestone）：语法高亮（节、键、规则类型、策略名、注释、字符串）、行号、诊断标记（行号旁图标 + 底部诊断列表，点击跳转）、查找替换、常用符号键盘工具栏。
- **表单模式**：按节分组——
  - 通用：已知键的表单控件（开关、文本、列表编辑），未知键以"原文条目"显示；
  - 代理：列表 + 按类型动态生成的编辑表单（字段对应 [04 §5](04-profile-spec.md#5-proxy)）；
  - 策略组：类型、成员选择与拖动排序、参数；
  - 规则：列表（可拖动排序）、添加规则面板（类型选择 → 值输入与即时校验 → 策略选择）；
  - Host、MITM（主机名列表）、重写各节、脚本。
  - 表单无法表示的条目（未知类型、复杂逻辑规则）以只读原文行显示，提供"以文本编辑此行"。
- 保存：校验 → 有 error 级诊断时阻止保存当前配置为运行配置（仍可保存文件）→ 当前配置则提交并重载。
- 托管配置：顶部只读横幅，提供"复制为本地配置""立即更新"。

### 7.3 模块

- 列表：名称、描述、启用开关、拖动排序（即叠加顺序）、错误标记。
- 安装：从 URL、从文件；确认页显示元数据、参数、将添加的 MITM 主机名与脚本（让用户知道模块会解密哪些主机）。
- 详情：参数编辑、来源与更新时间、诊断、查看源码。

## 11. 状态与错误呈现

- **空状态**：每个列表都有空状态说明与主要操作（如策略页无配置时"导入配置"）。
- **隧道未运行**：依赖隧道的页面显示"未连接"占位，并提供"连接"按钮；能离线工作的功能（规则测试、编辑器、DNS 手动查询之外的工具）照常可用。
- **错误文案**：按错误码在 String Catalog 中查找；未知错误码显示通用文案 + 码。
- **破坏性操作**：删除、重新生成 CA、清除数据，一律二次确认。

## 12. App 结构

实现（M2-11）：五个标签的骨架。首页（连接、当前配置、出站模式与全局策略、流量速率 / 曲线 / 累计、常用策略组、提醒）、策略页（`select` 组点击成员选择，节点的可用性与 UDP 能力；测速在 M3）、请求页（最近 / 活跃、1 Hz 增量拉取、列表最多保留 2000 条、基础详情）、配置页（列表与切换、从 URL / 文件导入及导入确认页、删除）、工具页（诊断：内存、hev 统计、网络快照、版本）。各标签的状态暂由视图内的 `@State` 与 `AppModel` 持有，独立的标签模型在 M4 拆分。`ProfileStore` 负责配置库与提交运行包。`MockTunnelClient` 提供示例、空状态（`empty`）与错误（`failing`）三套 fixtures，每个页面都有对应的 `#Preview`。


- SwiftUI App 生命周期；Observation（`@Observable`）模型，均为 `@MainActor`。
- 根模型 `AppModel` 持有：`AppEnvironment`、`TunnelController`、`TunnelClient`、`ProfileStore`、`ModuleStore`、`ResourceManager`、`CertificateManager`、`StatusObserver`（Darwin 通知 + 快照）。
- 各标签有自己的模型（`HomeModel`、`PoliciesModel`、`RequestsModel`、`ProfilesModel`、`ToolsModel`），通过环境注入。
- 轮询用视图生命周期内的 `.task {}` 循环，离开页面自动取消。
- 所有依赖隧道的访问经 `TunnelClientProtocol`；预览与测试使用 `MockTunnelClient`（固定的 fixtures 数据）。**每个页面都必须有使用 mock 数据的 `#Preview`**，包括空状态与错误状态。
- 无障碍：图标按钮都有 `accessibilityLabel`；列表行组合为单个可读元素；动态字体下布局不截断关键信息。
