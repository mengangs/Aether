# 01 产品定义

## 1. 定位

Aether 是 iOS 上基于规则的网络代理客户端，面向需要精细控制流量去向、并愿意编写或导入配置的用户。它在系统 VPN 通道内运行一个本地网络引擎：每一个连接按用户规则选择去向（直连、拒绝、某个代理节点或策略组），在用户授权的域名上可以解密并改写 HTTPS 流量，并允许用 JavaScript 扩展行为。

产品原则：

1. **可解释**：任何一个请求都能回答"它为什么走了这条路"——命中的规则、经过的策略组、最终节点都可见。
2. **轻量**：隧道扩展运行在 iOS 严格的内存上限内（见 [02 §6](02-architecture.md#6-内存预算)），稳定优先于功能数量。
3. **兼容**：配置语法与业界主流同类客户端通用的 INI 风格语法兼容，用户已有的配置、模块、规则集和常见脚本应能直接或经少量转换后使用。
4. **隐私**：不内置任何统计、广告或第三方崩溃上报 SDK；所有数据留在设备上；导出默认脱敏。
5. **诚实**：做不到的能力（如 iOS 上按进程分流）明确标注不支持，而不是静默忽略或伪造结果。

## 2. 目标用户与典型场景

| 用户 | 场景 |
| --- | --- |
| 普通代理用户 | 导入订阅或配置，一键连接，按规则自动分流，在首页切换节点 |
| 进阶用户 | 自己编写规则与策略组，叠加模块，按 Wi-Fi / 蜂窝切换行为 |
| 开发与调试者 | 抓包查看请求详情，MitM 解密指定域名，用重写和脚本做 Mock、改写接口 |

## 3. 功能范围

按里程碑交付，编号与 [14-roadmap.md](14-roadmap.md) 对应。**v1.0 = M0–M6 全部完成。**

### 3.1 连接与隧道（M0、M2）

- 通过 Packet Tunnel 建立系统 VPN；首页开关连接、显示连接时长与状态。
- 出站模式：规则 / 全局代理 / 直连，运行中可即时切换。
- 系统 HTTP 代理入站（可关闭）+ TUN 全流量接管，两条入口共用同一套路由。
- 按需连接（On-Demand）：始终连接，或按 Wi-Fi / 蜂窝条件连接（M4）。
- 网络切换（Wi-Fi ↔ 蜂窝、休眠唤醒）后自动恢复。

### 3.2 配置（M1、M3、M4）

- 配置文件的导入：URL、文件（"用 Aether 打开"）、剪贴板、二维码。
- 托管配置：带 `#!MANAGED-CONFIG` 头的远程配置按间隔自动更新。
- 编辑：文本编辑（语法高亮、行内诊断）与表单编辑两种模式，二者无损互转，保留注释与顺序。
- 模块：安装、启用/停用、参数填写，叠加到当前配置。
- 节点订阅导入：通用 INI 代理行、Clash 系 YAML 的 `proxies`、URI 列表（`ss://`、`vmess://`、`trojan://`、`vless://` 等）。

### 3.3 分流（M1、M3）

- 规则类型：域名（精确、后缀、关键字、通配）、IP-CIDR（v4/v6）、GEOIP、IP-ASN、目标端口、入站端口、协议、网络环境（SSID / 网络类型）、HTTP URL 正则与 User-Agent（仅在可见时）、逻辑组合（AND / OR / NOT）、规则集、域名集、FINAL。
- 内置规则集 `LAN`（局域网与保留地址）。
- 规则测试工具：输入域名或 URL，展示逐条匹配过程与最终策略。

### 3.4 策略与节点（M2、M3）

- 内置策略：DIRECT、REJECT、REJECT-DROP、REJECT-NO-DROP、REJECT-TINYGIF。
- 代理协议（v1.0）：HTTP / HTTPS、SOCKS5 / SOCKS5-TLS、Shadowsocks（AEAD 与 2022）、Trojan、VMess（AEAD）、VLESS（无 flow），传输层 TLS、WebSocket，混淆 simple-obfs（http / tls）。
- 策略组：手动选择、自动测速、故障转移、负载均衡；组内可引用订阅（policy-path）并按正则过滤。
- 节点测速：单个、整组、全部；延迟与错误原因可见。

### 3.5 DNS（M2、M3）

- Fake IP（默认）与真实 IP 两种模式。
- 上游：系统 DNS、UDP DNS、DNS over HTTPS、DNS over TLS。
- `[Host]` 本地映射、按域名指定上游、DNS 劫持、缓存查看与清空。

### 3.6 MitM、重写与抓包（M5）

- 设备上生成根证书，引导安装与信任，显示信任状态。
- 按主机名列表解密 HTTPS；HTTP/1.1，HTTP/2 在 M7。
- URL 重写（重定向、拒绝、透明改写）、请求/响应头重写、Body 正则替换、本地映射（Map Local）。
- 抓包：记录请求/响应头与 Body（有上限），导出 HAR，复制为 cURL。

### 3.7 脚本（M6）

- 脚本类型：http-request、http-response、cron、event（network-changed）、generic（快捷指令 / 面板手动执行）。
- API 与主流客户端的脚本接口兼容：`$request`、`$response`、`$done`、`$httpClient`、`$persistentStore`、`$notification`、`$argument`、`$script`、`$environment`、`$utils`、`console`、`setTimeout`。
- App 内脚本调试：输入脚本与模拟请求，查看输出与异常。

### 3.8 观测（M2、M4）

- 请求列表（最近 / 活跃），详情含规则、策略链、耗时、流量、备注。
- 实时速率、按策略 / 按接口 / 按主机的流量统计。
- 日志查看与导出；隧道内存占用与诊断信息。

### 3.9 系统集成（M4）

- 小组件：状态 + 开关、流量、当前节点；锁屏小组件。
- 控制中心开关（iOS 18+）。🔬
- 快捷指令（App Intents）：启动 / 停止 / 切换、切换出站模式、选择节点、切换配置、开关功能、更新外部资源、运行脚本。
- URL Scheme：`aether://`（见 [10 §5](10-control-ipc.md#5-url-scheme)）。

### 3.10 进阶（M7，v1.x）

HTTP 控制接口、局域网共享代理（Wi-Fi 访问）、IPv6 代理、DNS over QUIC、HTTP/2 MitM、代理链（underlying-proxy）、Hysteria2 / TUIC（需技术预研）、WireGuard（需技术预研）、分享扩展、其它客户端插件格式导入、性能与内存深度调优。

## 4. 非目标

以下内容明确不做，评审中出现时直接拒绝：

| 项目 | 原因 |
| --- | --- |
| 按进程 / App 分流（PROCESS-NAME 等） | iOS 的 Packet Tunnel 拿不到发起连接的进程信息。配置中出现时解析并提示"iOS 不支持"，规则不生效 |
| 源 IP / 源端口规则（SRC-IP、SRC-PORT） | TUN 流量经用户态协议栈转发后源信息无意义；仅在局域网共享入站（M7）上可能支持 |
| 私有或未公开规范的协议（如 Snell 新版本、Ponte） | 无公开规范，无法独立实现与验证 |
| XTLS Vision / REALITY、uTLS 指纹伪装 | 需要修改 TLS 握手细节，标准 TLS 库无法实现 |
| macOS / watchOS / tvOS 版本 | 聚焦 iOS / iPadOS |
| 内置节点服务、账号体系、付费墙 | 工具定位，不提供网络服务 |
| 任何统计、广告、第三方崩溃上报 SDK | 隐私原则；稳定性数据通过 MetricKit 在本地查看 |
| 使用 Apple 私有 API | 稳定性与合规 |

## 6. 本地化

- 界面语言：简体中文（开发基准语言）、英文。使用 String Catalog（`.xcstrings`）。
- 配置关键字、规则类型、日志中的错误码不翻译；错误的人类可读说明翻译。
